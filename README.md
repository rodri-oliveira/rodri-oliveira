## Projeto em destaque

### AtendeJá – Chatbot, Operações e Relatórios

Backend FastAPI + frontend React/Vite, autenticação JWT, importação de CSV e dashboards operacionais.

- Backend: FastAPI (Python 3.11), SQLAlchemy + Alembic, `structlog`, endpoints `/auth`, `/metrics`, `/admin` e `/health`.
- Frontend: React 18, Vite, TypeScript, Tailwind e ECharts; rotas protegidas por JWT.
- Relatórios: filtros por período, canal e intervalo de datas na interface e API.
- Integrações: estrutura para WhatsApp Cloud API/BSP, com webhooks e providers desacoplados.
- Qualidade: testes com pytest/vitest, CI e documentação de arquitetura e operação.
- Repositório: [atendeJA-ND-Imoveis-](https://github.com/rodri-oliveira/atendeJA-ND-Imoveis-)

> Valor: domínio de back-end de produção — autenticação, dados, logs, métricas — e capacidade de montar o front-end necessário para validação e boa UX.
